# MoonArrow 路线图

MoonArrow 面向 MoonBit 的标准列式数据交换：用纯语言实现可复用的 Arrow IPC
子集，并让外部生产的数据能被 MoonBit 读取、变换和重新写出。当前开发版尚未发布；
Mooncakes 上的 0.1.0 仍是初始七种基础类型版本。

## 本轮已落地

- 扩展整数、浮点、时间、Large/Fixed 二进制和 List、Struct、Map 等布局。
- 增加顶层 Utf8/Binary 字典、跨批次状态及文件索引；加入专门的字典预算。
- 加入类型化 `BatchBuilder`、`Table` 和批次操作、检查器和摘要。
- 实现任意字节切分的 stream 增量读取及逐批输出 API。
- 独立 MoonBit 消费模块、两个 PyArrow 文件工作流、Native/JS 基准。
- 四后端本地测试、Native/JS 独立互操作、CI 源码规模门禁。

详见[实施状态](IMPLEMENTATION_STATUS.zh-CN.md)、[格式契约](FORMAT.md)
和[验证记录](VALIDATION.md)。

## 后续优先级

1. 给应用提供真实文件/网络 I/O 适配器，让增量 API 能处理超过命令行参数
   限制的数据；现在的工作流仅验证小型真实文件。
2. 引入一个真实下游使用者的反馈，特别确认所有权、错误处理、跨版本迁移。
3. 扩展独立互操作语料到官方 Arrow 集成格式，再决定是否支持压缩、Decimal
   与其余复杂类型。每个新特性都必须连同外部 fixture、畸形输入和文档落地。
4. 稳定开发版 API、审查发布产物后再单独发布 Mooncakes 版本；比赛材料与
   正式提交另行执行。当前 CI 配置不能代替远端通过记录。

性能重点是减少不必要的数组复制和大批次分配。当前基准为单机 debug 构建
快照，不用于跨实现速度排名。并行计算可在应用层按批次分工；本库暂不提供
线程池、任务调度器或共享内存层。
