# Initial local validation

Validated on Windows, 2026-09-07, with moon 0.1.20260803 and PyArrow 21.0.0.
These results describe the implemented subset; see FORMAT.md for limitations.

| Check | Result |
| --- | --- |
| `moon check --target all --deny-warn` | Passed, four targets |
| `moon test --target all` | 18 tests passed per target: native, js, wasm, wasm-gc |
| `python tools/interop.py --target native` | 80 independent assertions passed |
| `python tools/interop.py --target js` | 80 independent assertions passed |
| `moon fmt --check` | Passed |
| `moon run cmd/main --target native` | 1066-byte file, 1 batch, 2 rows, 1 null name |

The 18 tests include the README example and a stream fixture generated by
PyArrow, plus malformed-input checks and mutation of each byte of sample IPC
streams/files. Mutation tests require successful decoding or a checked error;
padding and ordinary value mutations may remain valid.

The 80 interoperability assertions per target cover MoonBit-origin samples,
seven deterministic randomized cases with three batches each, V4/V5 legacy
framing, schema-only input, sliced arrays, unsupported types and compressed
input rejection. Each supported external input is decoded in MoonBit and
rewritten as both a stream and a file for PyArrow's full validation.

The GitHub Actions matrix is configured for Linux and Windows but has not run
on a remote repository. Linux results, a full Apache Arrow integration run and
performance benchmarks have not been measured. Initial Native compilation
emitted a warning about `rand_s` in the installed MoonBit runtime's `env.c`;
the project type checker reported no warnings and Native tests passed.

Source repository: https://github.com/buildliming/MoonArrow. Registry publication and contest submission have not been performed.
