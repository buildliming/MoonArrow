# UCI Iris data

`iris.csv` contains the 150 observations from Fisher's Iris dataset, with the
three class names normalized to `Iris-setosa`, `Iris-versicolor`, and
`Iris-virginica` for the workflow example.

Source: R. A. Fisher, [Iris](https://doi.org/10.24432/C56C76), UCI Machine
Learning Repository. The dataset is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
